# Credits and video

BDS-OS is a project directed by **freidtechnerd-hue**, created with assistance
from **ChatGPT GPT-6.1 Sol and GPT-6 Astra**.

Watch the creator's [original YouTube video, starting at 0:10](https://www.youtube.com/watch?v=oUb6CiOTym4&t=10s).
The repository includes development and fixes made **after the video was
released**. Consult the current documentation for features and installation.

The OS builds on GRUB, doomgeneric/DOOM, Freedoom, InfoNES and the PicoPlus
mapper adaptation, lwIP, Gumbo, Elk, LodePNG, minimp3, and font8x8.
Their authors retain their copyrights. Full attribution, pinned revisions and
licenses are in [the notices](../licenses/NOTICE.md).

The creator supplied the cloud wallpaper. Desktop icons, system melodies and
the generated boot illustration were added during development. Commercial
ROMs used privately for testing are excluded from the public distribution.

This is an independent hobby project, not an official OpenAI product.
