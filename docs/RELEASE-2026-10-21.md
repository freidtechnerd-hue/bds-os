## Changes

- Automatic preferred monitor size from validated EDID; 4:3, widescreen and
  modern modes through 3840×2160. Settings → Display → Auto detect / U → Keep
  saves automatic selection. Existing manual resolutions remain manual.
- Native libdvdnav menu VM with first-play/autoplay, keyboard and mouse menu
  buttons, title/program navigation and M to return to the root menu.
- Native certificate-validated TLS 1.2 and HTTP/HTTPS redirects. Browser page
  capacity rises from 64 KiB to 2 MiB. Wikipedia and example.com load inside
  the guest; self-signed, expired and wrong-host certificates are rejected.

## Requirements and limits

Use BIOS/CSM, at least 256 MiB RAM for installation and 128 MiB for installed
boot. Media Player and ClassiCube require SSE2. HTTPS requires CPU RDRAND and
a valid UTC hardware clock; QEMU can use `-cpu max -vga std` with a supported
Ethernet adapter. Only modes exposed by the firmware can be selected. Auto
reads monitor data at boot; it does not follow host-window resizing or hotplug.

Wikipedia currently uses simplified text layout with links. Full PC-equivalent
CSS, images, Unicode and JavaScript behavior are not implemented. TLS 1.3,
revocation fetching and Firefox-specific trust policy are also not implemented.
See [HTTPS details](HTTPS.md).

DVD autoplay runs when Media Player opens or DVD/CD is selected. Automatic
application launch on disc insertion is not implemented. CSS-encrypted discs,
UDF-only discs and subtitle/SPU overlays are unsupported; highlights use a
rectangle rather than the authored palette. Physical hardware and this new
build's VirtualBox path have not been verified. The previous checkpoint's
VirtualBox cold boot with the 8 GB DVD attached remains a known limitation.

The public ISO contains Freedoom and the upstream ClassiCube texture pack,
with licenses. User ROMs, saves, worlds and downloaded DVD/music test fixtures
are excluded. Existing personal disks were not modified for this release.
