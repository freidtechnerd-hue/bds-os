## Limits

ClassiCube is offline single-player with software rendering and no game audio.
DVD playback has no CSS decryption, menus, subtitles, DTS or Blu-ray support.
Only the first supported audio stream is selected; VOB transitions can gap.
MP4/H.264 and modern streaming sites are unsupported. Physical CD-DA extraction
is experimental legacy IDE ATAPI; BIN/CUE and optical data-file playback are
the verified paths. See [MEDIA.md](MEDIA.md) for complete format/seek limits.

Legacy BIOS/CSM, PS/2, firmware storage and VBE RGB32 are required. USB hotplug,
UEFI-only boot, NTFS/exFAT/ext4, native AHCI/NVMe and arbitrary hardware drivers
are not implemented. HTTP/basic CSS/limited JavaScript remain available;
HTTPS and modern browser compatibility are not implemented.

and matching Ubuntu GRUB 2.14-2ubuntu2 sources accompany the release.
