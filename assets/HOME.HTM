Welcome to BDS Browser

A small native browser compiled with the open source Gumbo HTML5 parser and lwIP TCP/IP stack.

Browse over Ethernet

Click the white address field, type a website, then click Go or press Enter. Ctrl+L, F2 or L also focus it. You can omit http://. The status shows your DHCP address.

NeverSSL is an HTTP-only page you can try.

Controls

  • Tab selects a link; Enter follows it.
  • Up/Down and Space scroll. R reloads. H returns home.
  • O or File/Open opens a local HTML or text file.
  • Ctrl+F switches fullscreen. ESC returns to the desktop.

Styles and scripts

JavaScript demo

Basic CSS colors, backgrounds, bold text, alignment and simple selectors are supported. The Elk JavaScript subset supports let variables, arithmetic, conditionals, for loops and function expressions, document.write and a small DOM API. HTTPS, full browser layout, cookies, forms and downloads remain unsupported.
